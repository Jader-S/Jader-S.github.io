> 2026 年 11 月 13 日。静奢主题的背景有一层字符雨，稀疏、短促、带拖尾淡出，是用来做纹理的，不是用来读的。我给自己定的改动很小：把字符集里那些 `*+-<>·.` 和数字去掉，只留 `JaderAI.cn`。改完觉得「既然现在能看出字了，那就让它更好认一点」——这一念之差，来回返工了三遍。

## 本来要改的只有一行

`GlyphRain` 是一个 WebGL 着色器：字符图集按网格排好，片元里算 `idx` 决定画哪个字，`gate` 决定这一格点不点亮，`b` 决定亮度。原始字符集是 `JADERAIjaderai0123456789*+-<>·.`，取字靠 hash 随机。

我最初想动的就是一行：字符集换成 `JaderAI.cn`。后来又补了一条：字符别随机，按固定顺序展示，多个字符串之间加一个空格分隔。两条都只关乎「显示哪些字、按什么顺序」，没有一条说要动效果。

所以正确的改动就是两处：字符索引从随机 hash 变成沿列循环计数，字符集末尾补一个空格。

## 我多做了什么

为了让「JaderAI.cn」能一眼读出来，我给组件加了一整套 `sequence` 机制：

- 新增 `sequence` 选项和 `uSeq` uniform，在 `glyphMask` 里开固定顺序分支；
- 把 `gate` 从「按周期随机点亮」改成「按列整体常亮」——**原来被点亮的只是短促流光，现在整根柱子一直亮着**；
- 把亮度 `b` 从 `clamp(uTrail / (phase * 22.0), 0.0, 1.3) - 0.04`（拖尾淡出）改成固定 `0.85`——**淡出没了**；
- 中途还把 `density 0.16→0.45`、`glow 1.15→2.4`、`cell 14→22`、`trail 0.7→1.0`、`speed 0.22→0.16` 一起调高。

效果从「一层克制的背景纹理」变成「一屏常亮的字符柱」。我要的一直是前者，却为了「让人一眼读出字」把整套效果换掉了。

更糟的是第二遍收手时，我只把密度、亮度、字号这些数值调回原值，**没有撤销 `sequence` 机制本身**。常亮逻辑还在，页面看起来几乎没变，字符还带着镜像。参数回调不等于撤销机制——这是我这次最实质的教训。

## 先把边界收回来，再改那一处

第三遍动手，我决定不碰任何视觉参数，按两步走。

**第一步：证明基线回来了。** 删掉 `sequence` 选项、`uSeq` uniform、固定顺序分支、整列常亮、固定亮度，恢复原始的 `gate` 和 `b`。然后用 `git diff <基线 commit>` 验收：与最初版本的差异必须**只剩必要改动**，任何多余的行都不能留。这一步比看截图可靠得多——截图只能告诉我「好像差不多」，diff 能告诉我「到底改了什么」。

**第二步：只改字符选取。**

```glsl
// 原来：hash 随机取字
float tick = floor(uTime * uMutate * 1.6 + hash21(id + seed) * 9.0);
float idx = floor(hash21(id * 1.71 + vec2(seed + tick * 7.31, tick * 0.613)) * uGlyphCount);

// 现在：沿列按字符集固定顺序，沿用原有 mutate 节奏缓慢滚动
float idx = mod(floor(id.y + uTime * uMutate * 1.6), uGlyphCount);
```

不新增 uniform、不动 `gate`、不动 `b`、不动任何密度亮度参数；`seed` 变成死参数后顺手从函数签名和调用处一起清掉。

空格分隔有个小坑：`buildAtlas` 里原本是 `filter((g) => g.trim().length > 0)`，会把空格直接吃掉，字符串之间根本没有间隔。改成让空格保留为一个**空白字形**——占一个图集索引、不绘制任何像素，循环自然变成 `JaderAI.cn JaderAI.cn …`。

另外保留了一处真正的修复：删掉 `f.x = 1.0 - f.x`。这行原本把每个字形在单元格里做水平翻转，随机字符雨里看不出来，一旦字符变成可读单词，全成了反字。

## 一条规则

**只改文案 / 换字符串时，就只改那一处。** 能顺手做的只有修 bug（比如镜像），不该顺手升级渲染机制、提升可读性、调整视觉参数。真想动，单独拎出来做一轮，别混在同一笔改动里。

原因不是「别多干活」，而是**多动的每一个变量都会让问题失去归因能力**：效果不对时，说不清是字符顺序、常亮逻辑还是密度的问题。三遍返工里，前两遍都耗在拆我自己加上去的东西。

还有一点值得记：回到稀疏拖尾雨之后，同一时刻每列只亮出一小段，完整字符串要看连续帧才读得全，空格间隔也很淡。这是原始效果的固有属性，不是缺陷——我决定先这样，别再为了「更清楚」去调点亮长度。
