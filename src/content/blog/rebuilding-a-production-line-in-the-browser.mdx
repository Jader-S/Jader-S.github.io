> 2026 年 11 月 12 日。这是我很早以前就想重做一遍的东西：2019 年毕业之后的第一份工作，就是给航天产线做数字孪生。联夯是一家上海公司，「首都航天机械」是我当时参与的北京项目——两个名字常被混成一个地点，其实一个是公司、一个是项目，并不矛盾。这次我用纯前端把那段经历重做成一个能点开的作品。

## 想做成什么样

成品是一屏：3D 数字孪生工厂线铺满整个背景，四周浮着半透明的科技风 HUD 面板（直角括号边框 + 青色微光），中央的 3D 场景仍然可以拖拽旋转，浮层的数据照常刷新，互不干扰。顶部是品牌条、KPI 和实时时钟，左列设备状态分布与产线产出，右列 OEE、开动率、告警等级，底部一张滚动的实时报警表。

数据全部是前端模拟，每 1.6 秒走一格。没有后端、没有额外依赖，用的就是工程里已有的 Three.js 和 ECharts。这么做有个很实际的好处：**随时能录屏、随时能演示**，不用先连一套环境。

## 几个我花了心思的技术点

**让图表跟着主题走，而不是另配一套色。** ECharts 的 option 里最容易埋雷的就是硬编码颜色。我的做法是用 `getComputedStyle(document.documentElement)` 把 `--neon-cyan`、`--neon-purple`、`--text-dim` 这些 CSS 变量读出来，所有图表都拿它们上色；再用 `MutationObserver` 监听 `<html>` 的 class / `data-theme` / style 变化，一变就重读一次。这样画质档或主题切换时图表自动跟随，零额外开发，也不会出现「面板换了皮肤、图表还是旧配色」的割裂。变量缺失时留了兜底色，不至于整片变黑。

**ECharts 在 React 里最容易漏的那两件事。** 我封了一层 `EChartPanel`：初始化走 `echarts.init(ref, undefined, { renderer: 'canvas' })`，`ResizeObserver` 监听容器尺寸调 `chart.resize()`，卸载时 `ro.disconnect()` 加 `c.dispose()`。这两行清理看着不起眼，但这类大屏面板多、切换频繁，不 dispose 就是稳稳的内存泄漏。option 用 `useMemo` 缓存，`setOption` 带 `notMerge: false, lazyUpdate: true`，避免每次 tick 都触发无谓的重渲染。

**让模拟数据「活」起来，而不是跳数字。** 我写了个 `stepData`：24 点趋势用正弦加噪声再做滑窗，OEE、健康度、仪表指针用带限幅的随机游走，设备状态四类占比跟着在线总数联动，每 tick 有 20% 概率注入一条新告警（严重 / 预警 / 提示，截断到 8 条），实际产量累加、故障次数和时长各自游走。关键是 `clamp` 和 `walk` 两个小工具把数值锁在合理区间——随机游走不设限，跑几分钟就会漂到一眼假的程度。

**3D 与 HUD 叠层。** 背景是 `FactoryLine`，拆成场景装配、机械臂加工、零件成型与飞向装配点的路径动画、工位与环境几个子模块，仿真纯逻辑单独有单测。它既能作为大屏的背景层（`bare` 模式），自己本身也是一个独立 Demo。视觉语言跟全站一致，深空加霓虹。

## 顺手补上的两个洞

做完之后我把它挂到了 p3 联夯项目下。之前这个组件虽然已经注册，却没有任何项目引用它，站点上找不到入口；而 p3 那张卡又只有标题、没有描述，点进去是「整理中」占位。一个「孤儿 Demo」加一个「空壳项目」，其实正好互补——用一次挂接把两个洞一起填上，详情页终于能讲清楚这段经历在做什么。

## 边界，以及我特意没做的事

有几件事我想写明白，免得这个 Demo 被误读：

- **数据是模拟的。** 我不会把它写成真实客户数据。想提高含金量，正确的做法是换上脱敏后的真实截图或真实图表数据，而不是给模拟值编一个出处。
- **体量确实大。** ECharts 加多个仪表再加 3D 背景，我把它放进懒加载，不占首屏预算。
- **桌面优先。** 这屏信息密度是按宽屏排的，竖屏还没单独适配，后面要按设备分级那套再收一版。
- **降级。** 每个 Demo 外层都有 Error Boundary，单个图表报错不会拖垮整页。

## 为什么执意要做这个

数字孪生这四个字，很容易做成一堆会动的模型。但我记忆里真正的工业现场是「节拍」：机械臂什么时候抬、零件什么时候成型、哪台设备掉线了、报警什么时候冒出来。所以这次我更在意的不是模型多精细，而是那条每 1.6 秒推进一次的数据流，和它跟 3D 场景对得上的感觉。

把七八年前第一次做的东西，用现在手里的技术重做一遍，还能放进自己的作品站里点开给人看——这件事本身，比任何一个参数都让我满意。
