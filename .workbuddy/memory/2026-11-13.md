### 关键架构决策（跨期复用）

- 弹框状态用 **zustand 外部 store**（`lib/blog-modal.ts` / `lib/project-modal.ts`），不用 Context：ASTRA 的 R3F `<Canvas>` 是独立 reconciler，Context 穿透不可靠；blueprint 绘制动画也从 React 树外发 action。命令式 API（`openBlog` / `openProject` / `openDemo` …）在任何位置都能触发。
- 弹框 / 抽屉一律 `createPortal(..., document.body)`：particle 有 snap-scroll 容器、atelier/blueprint 有 transform 层，直接渲染会被裁剪。统一壳层 `styles/shared/blog-modal.module.css`，两个弹框都 9999，故在 project-modal store 里单向 `closeBlogModal()` 互斥。
- `output:"export"` + 主题页全是客户端组件 → 博客正文必须构建前固化，不能运行时读 `fs`；改 MDX 后要重跑 `npm run gen:blog-content`。
- 移动端显隐用 **CSS 媒体查询**，不用 JS 首帧视口分支，避免 SSR hydration mismatch；`useViewport()` 只做跨断点 state 同步。
- Demo 实现只保留一份（物理移动而非复制）；`@astra/*` 是根级 tsconfig paths，shared 目录下仍解析成功；`vitest.config.ts` 的 alias 必须数组且 `@astra/` 排在 `@/` 前。
- Windows 文件锁会挡住 Git Bash 的 `mv` / `git mv`，批量移动目录用 PowerShell `Move-Item`。
- **语言只有一个真源**：根 `I18nProvider.locale`；`@astra/i18n` 的 `useT()` 是桥接层，只读根 locale，被 19 个 astra 组件 + 2 个共享 Demo 复用。改语言一律调 `setLocale()`，不要再写 `prefs.language`。
- **静态站做旧锚点兼容**：`output:"export"` 无 redirects / rewrites，在合并后的 section 内放不可见 `<span id="旧锚点" aria-hidden="true" />` 即可让浏览器原生 hash 滚动兜底；不要加 hashchange 监听（`ssr:false` 主题会有挂载竞态）。
- 导航文案只维护 `lib/i18n/locales/*.ts` 的 `nav` 一处；blueprint / particle NavBar 曾硬编码 `LABELS`，已改成读 `t.nav`。章节编号 `01 ABOUT / 02 WORK / 02 · OPEN SOURCE / 03 SKILLS / 04 BLOG / 05 DOMAINS` 按六段顺序，开源段是 `#work` 子编号。
